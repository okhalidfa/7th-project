My project name is KeenKeeper

This is a simple  react project to track my interactions with my friends. Here I can record calls, texts, and video chats, and also I can see them in a timeline with analytics.

Technologies Used            
        React.js
        Tailwind CSS
        Recharts
        Context-Api 
        DaisyUi
        
Key Features
      Add and track interactions (Call, Text, Video)
      Filter timeline based on interaction type
      Visual analytics using a Pie Chart
